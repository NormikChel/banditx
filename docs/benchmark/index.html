Бенчмарк

Замеры против nginx на одном железе.

Все замеры на одной машине: Windows 11, 4 ядра, клиент и сервер на одном хосте. Инструмент — oha 1.16.0, 10 000 запросов, 50 конкурентных соединений.

Статика

banditx v0.3.3   Requests/sec: 5019   p50: 9.3 ms
nginx 1.27        Requests/sec: 2819   p50: 17.4 ms

banditx в 1.8 раза быстрее на этом сценарии. Важная оговорка: это не значит, что banditx лучше nginx как прокси. nginx писался под Linux и использует эмуляцию select() на Windows. banditx через tokio использует нативный Windows IOCP. На Linux сравнение почти наверняка будет обратным.

FastCGI через HTTP/2

banditx (h2 → FastCGI → Python)
  Requests/sec: 2561   p50: 7.1 ms   p99: 14.9 ms

Что важно

Цифры говорят не о качестве кода, а о том, что banditx — рабочая альтернатива на Windows, где nginx исторически слаб.
