Конфигурация

YAML-структура, секции server и routes.

Вся конфигурация описывается одним YAML-файлом. Изменения применяются на лету — перезапуск не нужен.

Секция server

server:
  listen: "0.0.0.0:8080"
  tls_listen: "0.0.0.0:8443"
  access_log:
    path: "access.log"
    format: json

Формат access log

  • combined — классический nginx-формат, парсится grep'ом
  • json — структурированный, одна строка на запрос, готов для Loki и ELK

Hot-reload

banditx следит за файлом конфига. Как только он меняется, новая конфигурация применяется атомарно: in-flight запросы доживают на старом снимке, новые идут уже по новым правилам.
