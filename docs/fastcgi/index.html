FastCGI

PHP-FPM, пул соединений, режим поверх HTTP/2.

banditx общается с FastCGI-бэкендом напрямую, без проксирования в HTTP/1.1.

Пул соединений

На каждый HTTP-запрос к FastCGI-маршруту берётся соединение из пула. Одно TCP-соединение обслуживает много запросов, handshake происходит один раз.

HTTP/2 вход

FastCGI может обслуживать запросы, пришедшие по HTTP/2 — без даунгрейда до HTTP/1.1. Это редкая фича, у open-source nginx такого нет.

Минимальный конфиг

routes:
  - prefix: "/php/"
    upstreams: ["127.0.0.1:9000"]
    kind: fastcgi
    doc_root: "/var/www/html"

Метрики пула

На /_banditx/metrics видны banditx_fcgi_pool_hits и banditx_fcgi_pool_misses. Если hits растут, а misses нет — пул работает.
