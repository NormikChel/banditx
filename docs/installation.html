Как поставить banditx: бинарник, Docker, cargo, systemd. Займёт меньше минуты.

banditx собирается в один статический бинарник. Никакого рантайма, никаких виртуальных машин, никаких менеджеров пакетов. Скачал — запустил — работает.

#Готовый бинарник

Самый быстрый способ. Скачиваешь архив под свою платформу из последнего релиза и распаковываешь в /usr/local/bin.

ℹПроверка подписи

Каждый релиз подписан minisign. Публичный ключ — в README репозитория. Если паранойя — сверь хеш из SHA256SUMS.

#Другие платформы

  • macOS (Intel / Apple Silicon) — banditx-aarch64-apple-darwin.tar.gz
  • Windows x64 — banditx-x86_64-pc-windows-msvc.zip
  • Linux ARM64 (RPi 4+, Graviton) — banditx-aarch64-unknown-linux-gnu.tar.gz
  • Alpine / musl — banditx-x86_64-unknown-linux-musl.tar.gz

#Docker

Образ весит ~12 MB на базе scratch. Внутри только бинарник и сертификаты.

#Из исходников

Нужен Rust 1.78+ и линкер. Собирается за ~40 секунд на современном железе.

#systemd unit

Для продакшена — минимальный unit с hardening-флагами. Никаких RuntimeDirectory и User=www-data, потому что banditx умеет работать непривилегированно и биндить 80/443 через AmbientCapabilities.

#Проверка установки

После запуска проверь три вещи: версию, валидность конфига и health-эндпоинт.

✓Готово

Если check вернул config ok, 12 routes, 4 upstreams — можно идти в Конфигурацию.

#Обновление

banditx умеет горячий рестарт. Обновление без даунтайма — это распаковать новый бинарник поверх старого и послать SIGHUP.
