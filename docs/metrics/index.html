banditx отдаёт метрики в формате Prometheus на отдельном HTTP-порту. Логи — структурные JSON, чтобы их можно было жевать любым парсером.

#Prometheus endpoint

⚠Не выставляй 0.0.0.0

По умолчанию bind — 127.0.0.1:9090. Если очень нужно наружу — добавь auth и ограничь по файрволу.

#Что отдаётся

МетрикаТипОписание
banditx_requests_totalcounterвсего запросов, с лейблами route/status/method
banditx_request_duration_secondshistogramлатентность (buckets: .001 … 10)
banditx_request_size_byteshistogramразмер запроса
banditx_response_size_byteshistogramразмер ответа
banditx_active_connectionsgaugeоткрытых соединений
banditx_upstream_healthgauge1/0 по каждому бэкенду
banditx_upstream_retries_totalcounterсколько было retries
banditx_circuit_breaker_stategauge0=closed 1=half 2=open
banditx_tls_cert_expiry_secondsgaugeсколько до конца сертификата
banditx_build_infogaugeверсия и hash сборки

#Логи

Формат — JSON Lines. Одно событие на строку. Поля стандартные, плюс произвольные из log.fields.

#Готовый дашборд

В репозитории есть dashboards/banditx.json — импортируется в Grafana одной кнопкой. Панели: RPS, p50/p95/p99, error rate, активные соединения, health бэкендов, срок жизни сертификатов.

#Health-эндпоинты

Отдельно от метрик есть два эндпоинта для балансировщика и Kubernetes.

ПутьНазначение
/healthzliveness — 200, пока процесс жив
/readyzreadiness — 200, когда конфиг загружен и все критичные upstream'ы healthy
/versionJSON с версией и git-хешем
