Маршрутизация

Префиксы путей, приоритеты, раздача по типам.

Маршруты описываются списком. Побеждает самый длинный подходящий префикс.

Пример

routes:
  - prefix: "/api/"
    upstreams: ["127.0.0.1:8000"]
    strategy: least_conn
  - prefix: "/static/"
    static_root: "/var/www/static"
  - prefix: "/"
    upstreams: ["127.0.0.1:3000"]

Порядок не важен

Не нужно располагать маршруты от частного к общему, как в nginx. banditx сам сортирует их по длине префикса.

Типы маршрутов

  • http — обычный реверс-прокси на HTTP-апстрим
  • fastcgi — проброс в PHP-FPM или другой FastCGI-бэкенд
  • static_root — отдача файлов с диска, никакого апстрима
