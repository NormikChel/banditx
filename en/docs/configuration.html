The config is a single banditx.yaml. No include, no scripts, no magic. Everything the proxy does lives in this file.

#Minimal config

This is enough to proxy example.com to a local backend over HTTPS with built-in ACME.

#Top-level schema

SectionRequiredPurpose
servernoglobal process settings
listenersyeswhat addresses and ports to listen on
upstreamsyesbackend pools, strategies, health checks
routesyesrouting rules
middlewarenoreusable middleware chains
metricsnoPrometheus endpoint and log format

#The server section

ℹworkers: 0

banditx is async (tokio). Instead of forking processes, it spawns worker threads. 0 (auto) is usually the right pick.

#The listeners section

Each listener is a bind with optional TLS and HTTP/2. For 80 and 443, use two listeners and one redirect route.

#The upstreams section

#The routes section

Routes are matched top-down. The first one whose rule matches wins. Order in the file matters.

#Environment variables

Any value in the config can be substituted from env via ${VAR} or ${VAR:-default}. Useful for secrets and ports.

#Validation

Before applying, always run check. It catches typos, dangling references and incompatible flags.

⚠Recursive references

If a route references an upstream that references a route — check will fail and refuse to start. By design.

#Hot reload

SIGHUP re-reads the config without dropping active connections. Listening sockets are reused, upstream pools are rebuilt, new rules kick in instantly.
