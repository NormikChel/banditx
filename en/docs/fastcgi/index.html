FastCGI

PHP-FPM, connection pool, HTTP/2 mode.

banditx talks to a FastCGI backend directly, without downgrading to HTTP/1.1.

Connection pool

For every HTTP request to a FastCGI route, a connection is pulled from the pool. One TCP connection serves many requests, handshake happens once.

HTTP/2 input

FastCGI can serve requests that arrived over HTTP/2 — without downgrading to HTTP/1.1. This is a rare feature; open-source nginx does not have it.

Minimal config

routes:
  - prefix: "/php/"
    upstreams: ["127.0.0.1:9000"]
    kind: fastcgi
    doc_root: "/var/www/html"

Pool metrics

On /_banditx/metrics you will find banditx_fcgi_pool_hits and banditx_fcgi_pool_misses. If hits grow and misses do not, the pool is working.
