Getting started

Installation, first run, minimal config.

banditx builds with plain cargo. Only Rust is required — no system libraries, no CMake, no OpenSSL.

Requirements

  • Rust 1.75 or newer
  • Windows, Linux or macOS
  • On Windows: MSVC or MinGW toolchain for TLS

Build

git clone https://github.com/NormikChel/banditx
cd banditx
cargo build --release

Run

./target/release/banditx banditx.yaml

By default two listeners are started: HTTP on 127.0.0.1:8080 and HTTPS on 127.0.0.1:8443. The HTTPS certificate is generated automatically.
