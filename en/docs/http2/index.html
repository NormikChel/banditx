HTTP/2

ALPN, streaming, flow control, TLS 1.3.

HTTP/2 turns on automatically when the client offers it via ALPN during the TLS handshake. HTTP/1.1 clients keep working — they just use the old code path.

What is supported

  • ALPN: h2 and http/1.1 on the same port
  • Stream multiplexing
  • Flow control in both directions
  • Stream priorities and dependencies
  • gzip compression of responses

WebSocket over HTTP/2

Via extended CONNECT per RFC 8441. Works when both the client and the backend support the protocol.

Verify

curl -k -v https://127.0.0.1:8443/
# Look for the line "ALPN: server accepted h2"

What is NOT supported

  • HTTP/3 and QUIC — on the roadmap
  • Server Push — removed from Chrome, not worth implementing
