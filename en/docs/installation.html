Installation

Install banditx: binary, Docker, cargo, systemd. Takes under a minute.

banditx builds into a single static binary. No runtime, no VMs, no package managers. Download, run, done.

#Prebuilt binary

The fastest path. Grab the tarball for your platform from the latest release and unpack it into /usr/local/bin.

ℹSignature check

Every release is signed with minisign. The public key is in the repo README. If you're paranoid, verify the hash in SHA256SUMS.

#Other platforms

  • macOS (Intel / Apple Silicon) — banditx-aarch64-apple-darwin.tar.gz
  • Windows x64 — banditx-x86_64-pc-windows-msvc.zip
  • Linux ARM64 (RPi 4+, Graviton) — banditx-aarch64-unknown-linux-gnu.tar.gz
  • Alpine / musl — banditx-x86_64-unknown-linux-musl.tar.gz

#Docker

The image is ~12 MB, built from scratch. Only the binary and CA certs inside.

#From source

Requires Rust 1.78+ and a linker. Builds in ~40 seconds on modern hardware.

#systemd unit

For production, use a minimal unit with hardening flags. No RuntimeDirectory or User=www-data required — banditx runs unprivileged and binds 80/443 via AmbientCapabilities.

#Verify the install

After start, check three things: version, config validity and the health endpoint.

✓Done

If check printed config ok, 12 routes, 4 upstreams — head to Configuration.

#Upgrade

banditx supports hot reload. Zero-downtime upgrade = unpack the new binary over the old one and send SIGHUP.
