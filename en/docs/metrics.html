Prometheus, ready-made dashboards, structured logs, alerts.

banditx exposes Prometheus-format metrics on a dedicated HTTP port. Logs are structured JSON, ready for any parser.

#Prometheus endpoint

⚠Never bind 0.0.0.0

Default bind is 127.0.0.1:9090. If you really need external — add auth and firewall.

#What's exported

MetricTypeDescription
banditx_requests_totalcountertotal requests, labeled by route/status/method
banditx_request_duration_secondshistogramlatency (buckets: .001 … 10)
banditx_request_size_byteshistogramrequest size
banditx_response_size_byteshistogramresponse size
banditx_active_connectionsgaugeopen connections
banditx_upstream_healthgauge1/0 per backend
banditx_upstream_retries_totalcounterretry count
banditx_circuit_breaker_stategauge0=closed 1=half 2=open
banditx_tls_cert_expiry_secondsgaugeseconds until cert expiry
banditx_build_infogaugeversion and build hash

#PromQL examples

#Logs

Format is JSON Lines. One event per line. Standard fields plus whatever you add in log.fields.

#Ready-made dashboard

The repo ships dashboards/banditx.json — one-click import into Grafana. Panels: RPS, p50/p95/p99, error rate, active connections, backend health, cert lifetime.

#Health endpoints

Separate from metrics are two endpoints for load balancers and Kubernetes.

PathPurpose
/healthzliveness — 200 while the process is alive
/readyzreadiness — 200 when config is loaded and all critical upstreams are healthy
/versionJSON with version and git hash
