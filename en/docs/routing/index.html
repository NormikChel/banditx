Routing

Path prefixes, priority, per-route kinds.

Routes are defined as a list. The longest matching prefix wins.

Example

routes:
  - prefix: "/api/"
    upstreams: ["127.0.0.1:8000"]
    strategy: least_conn
  - prefix: "/static/"
    static_root: "/var/www/static"
  - prefix: "/"
    upstreams: ["127.0.0.1:3000"]

Order does not matter

Unlike nginx, you don't need to list routes from most specific to most general. banditx sorts them by prefix length itself.

Route kinds

  • http — a regular reverse proxy to an HTTP upstream
  • fastcgi — proxy to PHP-FPM or another FastCGI backend
  • static_root — serve files from disk, no upstream
