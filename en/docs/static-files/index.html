Static files

ETag, Range, 304, safe paths.

Serving files from disk is why 80% of people install nginx. banditx supports it out of the box.

What is supported

  • ETag from mtime and size, honest 304 on If-None-Match
  • Last-Modified and 304 on If-Modified-Since
  • Range requests: 206 Partial Content for resumable downloads and video
  • Automatic Content-Type by file extension
  • Path traversal protection via safe_join

Example config

routes:
  - prefix: "/static/"
    static_root: "C:/Users/me/site/static"

gzip on the fly

If the client sends Accept-Encoding: gzip and the file is textual and larger than 256 bytes, banditx compresses it. Range requests are never compressed — that breaks semantics.
