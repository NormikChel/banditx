Fast reverse proxy in Rust

HTTP/1.1, HTTP/2 over TLS, FastCGI. No OpenSSL, no C dependencies. One binary, YAML config, hot reload without dropping connections.

DocsGitHub

HTTP/2 + TLS 1.3

ALPN, flow control, streaming. rustls + ring, pure Rust.

FastCGI

Works over HTTP/1.1 and HTTP/2. Connection pool to PHP-FPM.

Static files

ETag, Range, 304, path traversal protection.

Load balancing

round-robin, least-conn, ip-hash. Health checks every 3s.

Hot reload

Config changes apply without dropping connections.

Metrics

Prometheus on /_banditx/metrics.
