Fast reverse proxy на Rust

HTTP/1.1, HTTP/2 over TLS, FastCGI. Без OpenSSL, без C-зависимостей. Один бинарь, YAML-конфиг, hot-reload без разрыва соединений.

ДокументацияGitHub

HTTP/2 + TLS 1.3

ALPN, flow control, стриминг. rustls + ring, чистый Rust.

FastCGI

Работает поверх HTTP/1.1 и HTTP/2. Пул соединений к PHP-FPM.

Статика

ETag, Range, 304, защита от path traversal.

Балансировка

round-robin, least-conn, ip-hash. Health checks каждые 3 секунды.

Hot-reload

Изменения конфига применяются без дропа соединений.

Метрики

Prometheus на /_banditx/metrics.
